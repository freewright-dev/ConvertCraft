# ConvertCraft documentation

ConvertCraft is the desktop application in this repository; its Cargo package and executable are still named `transmute`. These documents describe the current source implementation, not planned features.

- [User guide](user-guide.md): installation prerequisites, queue controls, output behavior, and troubleshooting.
- [Formats](formats.md): recognized extensions, supported targets, image/data transformations, and FFmpeg presets.
- [Development](development.md): source layout, conversion lifecycle, build commands, tests, and extension points.

For an overview, see the [project README](../README.md). For the current feature inventory, see the [changelog](../CHANGELOG.md).
